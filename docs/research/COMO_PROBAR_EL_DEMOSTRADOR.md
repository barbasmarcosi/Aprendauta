# Verificación local del demostrador

Ejecutar desde raíz: `npm test` y `python3 -m http.server 8080`.
Abrir http://localhost:8080 en un navegador. Flujo: iniciar → dos preguntas diagnóstico (sin pistas) → tres de práctica (pistas a pedido) → tres finales (sin pistas) → resumen. No se usa red ni almacenamiento.

Este resultado acredita comportamiento técnico básico, no aprendizaje ni elegibilidad para uso con menores.
