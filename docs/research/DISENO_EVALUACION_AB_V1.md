# Formularios A y B — evaluación diagnóstica y transferencia

**Estado:** instrumento exploratorio que **NO ha demostrado equivalencia psicométrica**.

## Cambio respecto del demostrador v0

En v0, diagnóstico y transferencia medían habilidades distintas en algunos ítems. En v1 hay dos formularios (A y B) de **tres competencias compartidas**, con números y contextos distintos, para permitir una exploración cualitativa de desempeño independiente sin repetir exactamente el mismo enunciado.

## Matriz de alineación

| Competencia | Forma A | Forma B | Operación matemática pretendida |
| --- | --- | --- | --- |
| Equivalencias | 6/8 de canteros → 75 % | 9/12 de estaciones → 75 % | Relación parte/total × 100 |
| Porcentaje de cantidad | 25 % de 160 → 40 | 25 % de 240 → 60 | Un cuarto del total |
| Descuento | 20 % de $750 → $600 final | 20 % de $650 → $520 final | Hallar descuento y restarlo |

La versión **A → B** usa forma A al inicio y B al final; **B → A** invierte el orden. La alternancia manual del demostrador es para revisión de personas adultas: **no produce aleatorización**, no elimina efectos de práctica y no controla el contexto de prueba. Antes de realizar un estudio se deberá definir asignación válida, garantizar equivalencia de dificultad y separar instrumentos.

## Qué se puede y no se puede concluir

**Sí:** verificar que el código presenta tres conceptos análogos sin pistas ni explicaciones prematuras, y que se detectan aciertos en cada etapa.

**No:** inferir ganancia de aprendizaje a partir de diferencias de aciertos, generalizar dominio, asegurar retención o atribuir efectos al producto. Tres ítems son insuficientes para un diagnóstico fiable y no hay medición diferida ni grupo comparador.

## Separación de datos y explicaciones

- **Diagnóstico:** no se muestran pistas, modelos visuales, soluciones ni justificación hasta finalizar todo el recorrido.
- **Práctica:** se admiten representaciones, hasta dos pistas y dos intentos. Después de responder, el sistema muestra el procedimiento y una pregunta para reflexionar.
- **Transferencia:** también sin pistas, visualizaciones ni soluciones hasta el cierre.
- **Resumen:** expone tres resultados diferentes. No se muestra una etiqueta de capacidad ni «mejora de X %».
- **Sin persistencia:** el progreso desaparece al refrescar y no se transmite a servicios externos.

## Próximas validaciones necesarias

1. Docentes revisan que cada problema sea correcto, apropiado y comparable.
2. Se incorporan preguntas de **explicación del razonamiento** y diagnóstico de errores conceptuales.
3. Se preparan más ítems con calibración de dificultad y una evaluación diferida independiente.
4. Se comprueba que las personas entienden el propósito de las representaciones sin depender de ellas.
5. Si se contempla una investigación con menores: autorización, seguridad y procedimiento legal según [salvaguardas](../04_PROTECCION_INFANCIA_Y_DATOS.md).
